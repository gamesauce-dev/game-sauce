game-sauce

無料 · オープンソース · セルフホスト

あなたのゲームコレクションを、
自分のサーバーに。

game-sauce は、持っているゲームをカタログ化し、カバーを取得し、多くをブラウザーでプレイし、残りは PC のエミュレーターで起動し、ゲームパッドで操作するビッグスクリーンでライブラリ全体をテレビに映し出します。

ダウンロード 使い方 ★ GitHub でスターを付ける

Windows · macOS（Apple シリコン）· Linux · Docker、Unraid、Proxmox · Raspberry Pi

紹介ビデオを見る

ライブラリ全体を74秒で巡るツアーです。音楽付き。再生すると音が出ます。

すでにあるコレクションのためのすべて

家族全員のライブラリを、自分で管理するマシンにひとまとめに。

ビッグスクリーン：ライブラリをテレビに

すべてゲームパッドで操作でき、ボタンのヒントが画面に表示されます。

カルーセル：ゲームを選んでプレイ

なだらかな弧を描くカバーのフル画面の棚。ファミリーとプラットフォームを選び、矢印キー、マウスホイール、スワイプ、ゲームパッドでスクロールして、プレイを押します。

ブラウザーでプレイ

多くの古いコンソールは、ウェブページからそのまま動きます。ステートセーブとゲーム内セーブは、人ごとにあなたのサーバーに保存されます。「続きをプレイ」の行が、どこまで遊んだかを覚えています。

あなたの棚：持っているディスクとカートリッジ

本物の棚にある箱入りのゲームを、手動またはリストからカタログ化し、デジタルコレクションと並べて管理します。棚は人ごとに別々です。

棚も Steam も

Steam ライブラリをプレイ時間付きで取り込み、PlayStation、Nintendo、Xbox のゲームもリストから取り込めます。実際に持っているディスクやカートリッジも、ROM と並べて記録できます。

チャット：家族と連絡を取り合う

サーバー上のユーザー同士の非公開メッセージと、管理者からのお知らせ。何も自分のマシンの外には出ません。

PC でプレイ

ワンクリックで、自分のコンピューターにインストールした RetroArch、MAME、Dolphin などのエミュレーターでゲームを起動できます。ゲームはすぐ再起動できるよう保持でき、設定ページで各エミュレーターを設定できます。

ライブラリの横にゲームの詳細

クラシックとモダンの見た目、ライトとダーク。同じライブラリを、好みの表示で。

スクリーンショットは、内蔵のデモデータと生成されたカバーを使っています。

すでにあるコレクションのためのすべて

家族全員のライブラリを、自分で管理するマシンにひとまとめに。

フォルダーをその場でスキャン

すでにあるフォルダーを指定するだけ。ファイルはその場でカタログ化され、移動、名前変更、削除は一切されません。壊れたファイルが1つあっても、スキャンが止まることはありません。

カバーと詳細を自動で取得

ScreenScraper、TheGamesDB、IGDB、SteamGridDB から、自分のアカウントでカバー、説明、発売年などを取得できます。フォルダーから画像を取り込んだり、自分で画像をアップロードしたりもできます。

ブラウザーでプレイ

多くの古いコンソールは、ウェブページからそのまま動きます。ステートセーブとゲーム内セーブは、人ごとにあなたのサーバーに保存されます。「続きをプレイ」の行が、どこまで遊んだかを覚えています。

PC でプレイ

ワンクリックで、自分のコンピューターにインストールした RetroArch、MAME、Dolphin などのエミュレーターでゲームを起動できます。ゲームはすぐ再起動できるよう保持でき、設定ページで各エミュレーターを設定できます。

テレビ向けのビッグスクリーン

ソファで使う、ゲームパッド操作のフル画面表示：ロゴやマーキーが付いたゲームのホイール、お気に入りとコレクション、A〜Z のバー、画面上のマニュアル、ミュートできるサウンド。

コレクションと人

お気に入り、非公開のコレクション、非表示のゲームに加え、信頼できる人のアカウント（ダウンロードや管理のないプレイ専用アカウントを含む）を作れます。ユーザー同士で非公開のメッセージを送れ、管理者は全員にお知らせを掲示できます。

いつもすっきり

No-Intro と Redump の DAT でダンプを検証し、重複バージョンを見つけて残すべき最良のコピーを提案し、未使用の画像ファイルを整理します。ゲーム自体は削除しません。

棚も Steam も

Steam ライブラリをプレイ時間付きで取り込み、PlayStation、Nintendo、Xbox のゲームもリストから取り込めます。実際に持っているディスクやカートリッジも、ROM と並べて記録できます。

自分で運用

アカウントもサブスクリプションもクラウドも不要。ライブラリとそのデータは自分のハードウェアに残り、アプリからバックアップと復元ができるデータベースに入っています。

動くところを見る

内蔵のデモライブラリからの短いクリップが2つ。

ビッグスクリーン：ライブラリをテレビに

ゲームパッドとソファのために作られたフル画面表示。ライブラリからワンクリックで開き、ブラウザーかデスクトップアプリをテレビでフル画面にします。

  • すべてゲームパッドで操作でき、ボタンのヒントが画面に表示されます。
  • あるものはロゴとマーキー、ないものはカバー、そしてゲーム自身の画像をぼかした背景。
  • お気に入りとコレクションは専用の行に。新しいコレクションに名前を付けるための画面キーボードもあります。
  • ゲームのマニュアルを画面で読めます。エミュレーションに問題があるとされたゲームも確認できます。
  • 同じ画面から、ブラウザーでプレイしたり、この PC でゲームを起動したりできます。

カルーセル：ゲームを選んでプレイ

なだらかな弧を描くカバーのフル画面の棚。ファミリーとプラットフォームを選び、矢印キー、マウスホイール、スワイプ、ゲームパッドでスクロールして、プレイを押します。

  • ウェブページで動くゲームにはブラウザーでプレイ、設定済みのエミュレーターを起動するにはこの PC でプレイを使います。
  • お気に入りには、カバーとタイトルの横に金色のスターが付きます。真ん中のゲームも、その場でスターを付けたり外したりできます。
  • 文字を押すと、その文字で始まる最初のタイトルにジャンプします。
  • ゲームに動画があれば、そのゲームで止まったときにカバーの下で再生されます。

あなたの棚：持っているディスクとカートリッジ

本物の棚にある箱入りのゲームを、手動またはリストからカタログ化し、デジタルコレクションと並べて管理します。棚は人ごとに別々です。

  • ゲームをタイルで見るか、本物のケースのように立つ背表紙の棚で見られます。
  • 背表紙をクリックして引き出し、もう一度クリックでケースを手前に、さらにクリックで開きます：片側にマニュアル、もう片側にディスクかカートリッジが現れます。
  • ケースを裏返して裏面を見たり、マニュアルを画面で読んだりできます。
  • 自分の画像やマニュアルを追加したり、メタデータプロバイダーからカバー、背表紙、裏面、ディスクを取得したりできます。

チャット：家族と連絡を取り合う

サーバー上のユーザー同士の非公開メッセージと、管理者からのお知らせ。何も自分のマシンの外には出ません。

  • あなたと相手だけが読める、1対1の会話。
  • チャットでは、一人ひとりに専用の色が付きます。
  • 気が変わりましたか？数分以内なら、メッセージを二人とも取り消せます。
  • 管理者は、メンテナンスの予定など、全員に見えるお知らせを掲示できます。プレイ専用アカウントにも届きます。
  • プレーンテキストのみでリンクは使えず、すべて自分のサーバーに残ります。

ホームサーバーで

Docker、Unraid、Proxmox のコンテナで動かし、家中のどのデバイスからでも使えます。手順は導入ガイドにあります。

導入ガイドを読む

初めて起動したとき、あなたのために作られたアカウントが一度だけ表示されます。控えておき、設定でパスワードを変更してください。インターネットに公開する場合は、VPN か、HTTPS 付きのリバースプロキシの内側に置いてください。

よくある質問

ゲームは付いてきますか？

いいえ。game-sauce は、持っているゲームを管理するためのものです。ゲームや BIOS ファイルは含まれず、提供もされず、ゲームをダウンロードすることもありません：自分のコレクションを持ち込みます。プレイについては、ブラウザーでのプレイはオープンソースのエミュレーター EmulatorJS で動き、プレイを押したときにブラウザーが読み込みます。PC でのプレイでは、「エミュレーター」ページがエミュレーターと入手先を案内し、ランチャーは自分でインストールしたものを起動します。

本当に無料ですか？

はい。MIT ライセンスのオープンソースです。作成するアカウントも、サブスクリプションも、トラッキングもありません。一部のメタデータプロバイダーでは、サービスを使うために自分の無料アカウントの登録が必要です。

ブラウザーでプレイできるゲームは？

BIOS が不要な多くの古いコンソールは、ウェブページから動きます。新しいシステムや、ブラウザーにできる範囲を超えるものは、代わりにランチャー経由で PC のエミュレーターで起動します。

ファイルを移動したり変更したりしますか？

指定したフォルダーでは、しません。ファイルはその場で読み取られ、中のファイルを移動、名前変更、削除することは決してありません。整理ツールが触れるのは、画像と、game-sauce 自身が保存したファイルだけです。

家族みんなで使えますか？

はい。信頼できる人のアカウントを作ってください。コレクションは作成した人だけのもので、プレイ専用アカウントには、ブラウザーでプレイできるゲームだけが表示されます。

ヘルプや不具合の報告はどこで？

GitHub で issue かディスカッションを開くか、hello@gamesauce.app にメールしてください。設定の「システムの状態」ページで、秘密情報を含まない、コピー＆ペースト用のレポートを作れます。

game-sauce を気に入っていただけましたか？

game-sauce は無料のオープンソースです。役に立ったら、コーヒーをおごっていただけると嬉しいです。新機能、Windows・Mac・Linux でのテスト、質問への対応に、より多くの時間を割けるようになります。
