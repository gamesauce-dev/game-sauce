# Changelog

All notable changes to game-sauce. Newest first. Dates are `YYYY-MM-DD`.

## [Unreleased]

### Security
- **Upload library upgraded:** multer 1.x to 2.5 (the 1.x line has known vulnerabilities and is no longer patched). It handles ROM, cover, DAT and backup uploads; behaviour is unchanged and all tests pass. `npm audit` now reports no problems in the shipped dependencies.
- **Cross-site request check:** requests that change data are refused when the browser says they came from another website or address (CSRF). Scripts and `curl` are unaffected. Behind a reverse proxy set `GAMESAUCE_TRUST_PROXY=1`, or list the address in `GAMESAUCE_ALLOWED_ORIGINS`.
- **Rate limiting:** each signed-in user is capped at 900 requests a minute, with tighter caps for metadata lookups, downloads, uploads and backup/restore (`GAMESAUCE_RATE_LIMIT`, 0 = off). Cover art and the health check are never counted. Returns `429` with `Retry-After`.
- Login has a **Keep me signed in on this computer** box. Unticked, the session cookie disappears when the browser closes and the session also ends after 12 hours.
- **Idle timeout**: browser-only sessions sign out after 2 hours without activity (`GAMESAUCE_IDLE_MINUTES`); it can be enabled for persistent sessions too (`GAMESAUCE_IDLE_MINUTES_PERSISTENT`). Existing sessions stay persistent.

### Added
- **Platform icons.** Every platform now has a small pictogram, drawn in its own colour, in the sidebar and on the Sources list. They are original generic shapes (a home console, handheld, cartridge, disc, arcade cabinet, computer, controller or chip), not the console makers' logos. Each built-in platform has a sensible default, and an admin can pick another for any platform, or for one they add, under Settings, System setup, Platforms, Edit. (Database version 21.)
- **Pin the details window.** A pin button next to the close button keeps the game's details open beside the games, without the dark overlay: click another game and the window switches to it, and the games make room for it. Close it with the X or Escape; unpin to go back to the usual behaviour. Remembered on that device. On a phone, pinning only keeps it open (there is no room beside the games). Available to everyone, including play-only accounts.
- **Play-only top bar and grid size.** A play-only account has no sidebar: the logo, Library, the person's picture and name, settings and sign-out sit in a slim bar along the top, which gives the games the whole width (and on a phone, a one-line bar). It has the same comfortable / condensed grid switch as the full screen.
- **Search finds games by their platform.** Typing a platform's name, short name or family ("game boy", "snes", "nintendo") now lists its games, in the full screen and the play-only one.
- **A source can have several folders.** A collection is often split across drives. Each source card on the Sources page now has **＋ Add another folder**: pick it in the folder browser, and it is scanned straight away under the same name and platform. The extra folders are listed on the card (with a ✕ to stop scanning one; its games stay in the library) and shown as "not reachable" when a drive is away. An unplugged folder never wipes its games: they are left alone, and the scan says which folder it could not read, while a game that is really gone from a folder that IS reachable is still flagged missing. The same folder cannot be added twice or to two sources, and a file reachable from two of a source's folders counts once. (Database version 20.)
- **Browser play for Capcom CPS1 and CPS2**, and **CPS3 and Cave** can be switched on game by game (they use the same FinalBurn Neo core, but are not offered until a game has been seen running).
- **Building a list of verified arcade games.** The play-check tool (`scripts/check-play.mjs`) gains `--candidates` (also test games the app does not offer yet: MAME after the year cut-off, CPS3, Cave) and `--apply` now also switches browser play **ON** for those that ran, as well as OFF for those that showed the RetroArch menu. `--cutoff` finds the year where games stop working: it tries a few games per year, oldest first, and stops once two years in a row mostly fail, then prints the year to use. A new admin setting under **User accounts, Arcade browser play: verified games only** hides every arcade game from browser play until it has been switched on, so only games the tool saw running are offered.
- **Play check tool (`scripts/check-play.mjs`):** finds which games flagged "play in browser" really start. A game the browser core cannot run drops into RetroArch's own menu and the emulator never reports an error, so the tool loads each game in a headless browser from your PC (pointed at your server, signed in as an admin), looks at the picture and sorts games into running, RetroArch menu (a failure) and blank. It checks a random sample per platform by default (`--sample`), or everything (`--all`), a few games at a time, and writes `results.jsonl` plus a `report.html` with a picture of every failure. It only reads: saving is switched off, and test plays are not counted in Continue playing or the stats. `--apply` switches browser play off for the games that showed the menu (each can be switched back on from its ⋯ menu); `--resume` carries on an earlier run. See `docs/PLAY-CHECK.md`. A game on its attract screen (mostly black, like Ms. Pac-Man's) is correctly counted as running: "blank" now needs black with next to no other colours.
- **Play-only accounts.** In **Settings → System setup → User accounts**, each member now has a **Screen** setting: **Full** (everything, as before) or **Play only**. A play-only person gets a simple screen: just a grid of the games that can be played in the browser, a search box and a Favourites filter, and the detail window with a Play button (and favourite). No downloads, collections, sources, emulators, sorting or editing. Search and paging only ever see playable games, using the same rule as the Play button (platform has a core, MAME's year cut-off, and the admin's per-game on/off). It works on phones and tablets. They can still change their password and picture, and run the welcome tour. This is enforced on the server, not just by hiding buttons: a play-only account that types an address into the browser still gets "not allowed" for anything outside play, browse and favourites. Switching someone back to Full takes effect straight away, with no re-login. An admin always has the full screen.
- **Admins can hide a game from everyone.** The detail menu has **Hide from everyone** (and **Hide from me only**, which is the old personal hide, unchanged), and the selection bar has a matching **Hide from everyone** button for many games at once (with a confirmation). A game hidden this way disappears for members everywhere at once: the library, search, counts, collections and the recent row, and opening, playing, downloading or favouriting it by address answers "not found". Nothing is deleted. You find these games under **Hidden** (marked "hidden from everyone") and can show them again from there. Personal hiding still only affects the person who did it. (Database version 19.)
- **Welcome tour: Browse for the folder.** The "Add your first folder" card has a Browse button that lists the server's folders inside the card (Up, open, Use this folder), like the Sources page. The scan now carries on in the background so a big collection does not hold the tour up.
- **Welcome tour on first sign-in:** a short set of cards with Back / Next, a progress indicator and Skip. A new member is guided to change their password and add a picture. A new admin gets the same plus: where game details come from (IGDB, TheGamesDB and SteamGridDB keys, with links), downloading the LaunchBox database (with progress), and adding a first folder of games. Accounts that already existed are not shown it. **My account → Welcome tour → Run the welcome tour again** brings it back for anyone.
- **LaunchBox metadata provider (free, no key, local):** Settings → System setup → Metadata providers has a new LaunchBox card. **Download database** fetches LaunchBox's public game database (about 110 MB), indexes it on the server in about half a minute (streamed, so memory stays small; a failed download never replaces a working index), and shows its size and age. Lookups are then instant and use no quota. It matches by exact name (alternate names and roman numerals count, a partial name never does), prefers the cover for the right region and the release year you already know, and is also available in the manual match search. On console platforms it is asked **first**; arcade platforms keep their order. Games it cannot find fall through to IGDB / TheGamesDB as before.
- **One-command start for beginners:** `./start.sh` (Linux / macOS) or `start.bat` (Windows, double-click) installs what is needed on the first run, picks a free port, creates the first account and prints its password once, opens your browser, and keeps your library in a `game-sauce-data` folder in your home directory so updating the program never touches it. Options: `--lan` (let phones and tablets on your network connect), `--port`, `--no-open`, `--data`. A new **Quick start for a desktop** guide (`docs/QUICKSTART-DESKTOP.md`) walks through it in plain language.
- **Slow-request log** (Health, admin): every request that takes over a second (change the limit with `GAMESAUCE_SLOW_MS`) is listed with what it was, how long it took, who made it and how many other requests were already running. The app handles one request at a time, so one slow job can make everything feel stuck; this shows which one, instead of guessing. Kept in memory, cleared on restart.
- **Clear match** (admin): removes a wrong metadata match from a game (its cover, genre, description and other provider details) and puts it back to its plain name (from the names CSV or MAME list when there is one), ready for Fetch metadata or Identify. In the game detail it is in the **⋯ More** menu; in Select mode it applies to every selected game. A cover you uploaded yourself is kept, and files on disk are never touched.
- **Add a folder pre-selects the platform from the folder's name:** pick or type `.../roms/fbneo` and *FinalBurn Neo* is chosen (likewise `neogeo`, `cps2`, `mame`, `ps2`, `snes`, `megadrive` and many more spellings, matched without regard to case, spaces or punctuation). A short note says it was picked from the folder name. Folders with no clear match (`misc`, `games`) select nothing, and a platform you choose by hand is never overridden.
- **Genre pills in the game detail window:** each genre is its own label above the cover art (a game stored as "Shooter, Arcade" shows two). Tapping one lists every game with that genre. The genre filter now matches one genre inside a multi-genre field, so *Puzzle* also finds "Puzzle, Arcade" and "Shooter, Puzzle".
- **System entries:** BIOS, device and computer/console entries can be marked **System**. They stay in game-sauce and stay downloadable, but leave the main Library and are skipped by Fetch metadata. A new **⚙ System** filter lists them, and there Select all, Hide, Unhide, Collection and **Back to library** all work. Admins can also mark any selection **Mark as System** in Select mode. The Game names (CSV) tool marks them from `is_bios`, `is_device`, and an `is_arcade` column (a filled value that is not *yes* means not arcade; for MAME, add `yes` when the machine's `<input>` has `coins`). A machine with `is_arcade` = yes is always kept as a game, even if it is also flagged BIOS or device (the CPS3 sets share a BIOS yet are playable). The old *hide* option is still there as a second tick box.
- **Favourites warning before deleting:** if anyone has the game as a favourite, deleting it (one game or a bulk delete) asks first and names who ("This is a favourite of anna, ben"), with *Delete anyway*.
- **Duplicate finder: ties and legend.** When nothing separates the copies it says "No clear winner: check both" instead of suggesting one, and a one-line legend explains the green outline, the padlock and the tie mark.
- **Library tiles:** the favourite and hide icons are the same, larger size (and always visible on touch screens), drawn clearly instead of text symbols.
- **Lock** (admin): a padlock in the game detail's **More** menu and on every copy in the Duplicate finder. A locked game is protected from every kind of deletion and preferred in the duplicate finder until you unlock it. Locked games wear a green padlock badge on their tile, and their Delete button looks disabled with the reason in its tip.
- **Game names (CSV) can hide BIOS and device entries:** if the CSV has `is_bios` and/or `is_device` columns (`yes` marks a row), a tick box (on by default) hides those games when you apply the names. Preview shows how many there are. Hidden games are skipped by Fetch metadata, so BIOS and device files stop showing up as failed matches; they can be brought back from the Hidden filter.
- **Lock switch in the Duplicate finder:** every copy has a padlock (it was a star). Starring a copy makes it the one to keep and overrides the automatic suggestion (star several to keep several); the choice is saved and respected on every re-run, and **Hide the others** never hides a copy you starred. A starred copy is also **protected from deletion** (single delete, bulk delete, *Remove source + ROMs* and the orphan purge) until you switch the star off.
- **Hide in Select mode:** with games selected (one, several, or *Select all*), a **Hide** button sits beside Collection and Delete, in the top bar and in the selection bar. Nothing is deleted. When you are looking at the *Hidden* filter it reads **Unhide** and brings the selection back.
- **Game names (CSV)** (Settings, admin): pair each ROM file name with a proper game name from your own CSV (columns are selectable; defaults `rom_name` and `short_game_name`), pick a platform, **Preview** the renames, then **Apply**. Built for romsets such as FinalBurn Neo or MAME whose file names (`sf2ue.zip`) no cover database understands; afterwards **Fetch metadata** can find their covers. Works for any platform; files on disk are never touched.
- **Animated logo:** the "-sauce" gradient flows in a seamless loop (no jump), a bright band rolls fully across the name every few seconds, and the text glow pulses in vivid colour. The logo itself breathes gently (a slow swell of glow and size) instead of flashing. Switched off automatically for people who ask their system for reduced motion.
- **Profile pictures:** everyone can upload their own picture (Settings → Profile picture). It is cropped square and shrunk to 256 px in the browser, checked by content on the server (JPEG, PNG or WebP, max 1 MB; no SVG), shown next to your name in the menu and in the user list, and stored in the database so backups carry it. Only you can change yours; every signed-in person can see the household's pictures.
- **Duplicate finder** (Settings → Duplicate finder, admin): groups the different versions of one game on a platform (USA, Europe, Japan, revisions; arcade clones are grouped under their parent using the MAME name list), suggests one copy to keep (DAT-verified first, a favourite is protected, then region and revision), and offers **Hide the others**. Reversible: nothing is deleted and no file is touched. Platform filter and paging included.
- **Downloads per person:** each member can be set to Default, Always allowed or Never (Settings → User accounts). It beats the server-wide switch, takes effect immediately, and is audited. Admins can always download.
- **Proxmox installer** now explains the Console tab's `login:` prompt (the container has no root password on purpose; use `pct enter <id>`).
- **Health page** (Settings → Health, admin): database integrity, disk space, source folders reachable, last scan, backups (none, stale, failed), providers, encryption key location, and a **Copy report** button with no secrets, tokens or folder paths.
- **ARM64 Docker image:** the published image is now multi-architecture (amd64 and arm64: Raspberry Pi 4/5, ARM servers).
- **CONTRIBUTING.md** with what the project will and won't accept, how to run it and test it.
- **New README screenshots** drawn from an invented demo library with original cover art (no real box art), including the Health page.
- **Let members download ROM files** switch (Settings → User accounts). Off by default: members can browse and play in the browser, and the Download button is hidden for them; admins always can. Refused downloads are not counted, and changes are audited.
- **Reset password** for admins on every other user (Settings → User accounts): sets a new password, signs that user out everywhere and clears any sign-in lockout. A built-in Generate and Copy makes a strong one. The password is never written to the activity log.
- **More tiles in the home boxes:** the *Continue playing* and *Recently added* boxes now show as many games as fit on their one line (up to 12 and 16) instead of a fixed 6 and 9.
- **Proxmox LXC installer is now documented up front:** README has a "Option P" deployment section with the one-line command, the settings table and day-to-day commands; the "experimental" label is gone now that it has been run on real hardware.
- **Controller layout:** Nintendo-style pads (Switch Pro, many 8BitDo) now have A on the right button and B at the bottom, picked automatically from the controller's name. **Settings → Controller** lets you force Xbox or Nintendo layout.
- **Restore…** button on every backup kept on the server, so there is no need to download and re-upload it.
- **Close a running game with the controller:** hold Select + Start for a second (a progress bar shows). No other button is taken from the game.
- **Cleaner Library home:** search and the filter pills share one line; the home rows are smaller, collapsible (remembered) and side by side on wide screens; selecting a platform shows its name as a heading above the tiles.
- **Restore from backup** (Settings → Backups): upload a backup, review what is inside and any warnings, then confirm by typing RESTORE. A safety backup is taken first, the server restarts and swaps the data in, and the replaced data is kept in `data/pre-restore-<time>/`. Damaged or half-downloaded files, backups from a newer version and backups with no admin are refused.
- **Upload your own cover** for any game (JPEG, PNG or WebP, checked by content). It survives metadata refreshes and the clear-covers tool; **Auto cover** removes it.
- **Continue playing** row on the Library home: the games you last played in the browser, per user.
- **Retro-neon animated sign-in screen** (switches itself off for reduced-motion users).
- **Gamepad navigation** for the whole interface: D-pad or stick to move, A select, B back, X play, Y search, LB/RB for previous/next, with an on-screen legend.
- **Browser play** for platforms with a core: per-user save states and in-game saves, a MAME best-effort cut-off year and a per-game on/off switch.
- **Fluid scaling** from 1080p to 4K, and infinite scroll in the library.
- **MAME support:** zip-only sources, a `-listxml` name list importer, strict cover matching, **Fetch metadata** that runs through the whole library, and an admin tool to clear covers by platform.
- **README screenshots** (`docs/screenshots`) and a rewritten user guide covering all of the above.
- **Backups** (Settings → Backups, admin only): download a backup any time, or schedule them (6 h / 12 h / daily / weekly, keep the newest N, choose the folder). Each backup is a single `.tar.gz` with a consistent database copy, the encryption key, every user's saves and a manifest; imported ROMs, covers and media are left out.
- **Previous / next arrows** in the game detail panel (and the ← / → keys) to step through the games without closing it. It follows the list you opened the game from: the library grid (loading more tiles as you go), the recently added row, or a collection.

### Changed
- **Play-only top bar: Library button replaced by a back-to-top arrow.** The Library button only reset the view and scrolled up, so it is gone. Click the logo to go back to the library (for example from Settings), and use the new arrow beside the game count, just above the games, to scroll back to the top.
- **Play button on the tiles is green, and play-only matches the full screen.** The round play button on a game tile now appears only when you point at the tile (play-only accounts had it showing on every tile all the time, which hid much of the cover, worst in the condensed grid). It is a soft green instead of purple, to match the green play button in the details window. Touch screens, which cannot hover, still show it faintly.
- **Play check: `--resume` finishes the job.** A run without `--all` tests a random 20 games per platform; with `--resume` those 20 now come only from games not tested yet (before, it drew from everything, so a platform with 29 games crept forward by 5, then 3). A platform with only a few left is simply finished. The tool also says when a sample is all it will do and how many are left, and points at `--all`. New quick-reference table in the Play check guide (`docs/PLAY-CHECK.md`).
- **The password rule is bold** ("At least 10 characters, with a letter and a number") on the Change password screen, in the welcome tour, and in the admin's Reset password dialog.
- **Scanning large files is faster.** The checksum step used a slow JavaScript CRC32; it now uses Node's built-in one, which gave the same answers in every test and cut hashing time per gigabyte from about 4 seconds to about 2 on a test machine. The scan still has to read every byte of every new file, so a 140 GB game takes as long as the disk takes to read 140 GB.
- **Play check: `--apply` works as it goes, and skips games already switched on.** Each game's flag is changed right after it is judged, so stopping a long run (or the PC sleeping) keeps its progress. Games already switched on are skipped on the next run (they passed before); `--recheck` tests them again. Together with `--resume`, a run that is stopped and started again simply carries on with what is left.
- **Sources are grouped by platform family:** the list now has a small heading per family (Nintendo, Sega, Sony...) with the sources A to Z inside each, the same order as the platform picker, instead of one A to Z list that cut across families.
- **Adding a folder shows progress that stays:** the message now carries a spinner and stays on screen from the moment you press the button until the scan finishes, instead of vanishing after a couple of seconds.
- **Detail window: the previous / next bar is fixed in place.** It now sits in a pinned bar at the top of the window with the close button, in the same spot whether or not the game has genres, and it stays in view while you scroll the details.
- **LaunchBox card shows what is happening:** the button changes to "Starting…" at once, and a spinner, a progress bar and a percentage follow the download and the indexing.
- **Settings sub-options are more prominent:** bold white text on a brighter background, with a stronger highlight on the one you are in.
- **The duplicate finder reuses its answer for 30 seconds** instead of re-reading the whole library every time you open it, change the platform filter or lock a copy. Anything that could change the groups (lock, hide, System, rename, delete, upload, scan, a metadata run, platform edits) discards the saved answer straight away, so it never shows stale groups after a change.
- **Select checkbox moved to the bottom-left of each tile**, so it no longer covers the platform badge at the top-left. In Select mode the padlock and DAT badges that normally sit in that corner step up above the checkbox, and a game that is both locked and DAT-verified now shows the two stacked instead of overlapping.
- **Steady Library toolbar.** The sort order now sits right after the search box, and the top row (search, sort, filters, Fetch metadata, grid size) no longer moves or wraps when you select games. Every selection action (Add to collection, Hide, Mark as System, Clear match, Delete, Done) is in the selection bar underneath, which has Delete and Done set apart at the far right.
- **Settings is tidier: two levels.** Six group tiles on top (**My account**: profile picture, change password, controller; **Library tools**: DAT files, game names CSV, duplicate finder; **Maintenance**: database maintenance, backups; **Health & coverage**; **Security & activity**: active sessions, activity log; **System setup**: user accounts, metadata providers, platforms). Choosing a group shows its settings as a small row of tabs underneath. Every setting is where it was inside its group, the group you were in is remembered when you refresh or come back, and members only see the groups and settings that are theirs.
- **Duplicate finder shows where each copy lives:** the source name and full file path appear under each copy, so two entries with the same file name (for example one in a `fbneo` folder and one in a `mame` folder) can be told apart at a glance.
- **Hiding a game is now personal.** Hide (a tile, the detail window, Select mode, the duplicate finder's *Hide the others*) only changes what *you* see; other people still see the game, and the Hidden filter lists only your own hidden games. Hides made before this update were handed to the first admin, so nothing changes for them and nothing leaks to others. **System** is now the system-wide way to tuck things away: only an admin can mark or unmark a game as System, and System games are hidden from everyone's library (and skipped by Fetch metadata) but stay downloadable. The Game names (CSV) tool therefore marks BIOS/device/non-arcade entries as System (its separate *hide* option is gone). Also fixed: the *hidden* veil on a tile no longer blocks the unhide button.
- **Previous / count / next** controls moved under the cover art in the game detail, as wide as the art and a little smaller.
- **Fetch metadata keeps running when you refresh or close the page.** It is now a job on the server (Stop button included) instead of being driven by the browser. A progress box at the bottom right shows how far it has got, on every page, and reappears after a refresh. One run at a time; admin only.
- **LIBRARY in the menu always shows the whole library:** clicking it clears any platform you had selected and scrolls the grid back to the top.
- **Sidebar platform groups line up:** group headers (ARCADE, ATARI…) now start at the same left edge as the platforms under them, with the arrow sitting above the colour dots.
- **Settings header stays put:** the title and the tile menu are pinned to the top while the open module scrolls underneath, so you can always jump to another section. The tiles are more compact to leave room.
- **Sidebar menu redesigned:** UPPERCASE bold white labels, new drawn icons (library, collections, sources, add ROMs, emulators), an accent bar on the current page, and a smaller gap under the user box.
- **Calmer Library home:** *Continue playing* and *Recently added* each sit in their own neon rounded box on a single line (no scroll bar), with a white divider before the main grid. Short windows start with the boxes collapsed.
- **Game detail window:** the previous / next / count controls are squared green tiles centred above the cover, the cover is smaller, and the action buttons are now icon-only with a hover tip (download, play, favourite, collection, browser-play switch, hide, refresh metadata, upload cover, delete).

### Fixed
- **Save state works again in browser play.** Every Save State ended in "FAILED TO SAVE STATE". The current EmulatorJS front end asks the game core for its state through a function the cores on the CDN do not have yet (they only offer the older one), so nothing could be read. The player now reads the state the way the cores offer it, and still uses the new function if a core has it. Tested on a real game: the state was saved to the account with its screenshot, and loaded back. (Nothing to do with your account type; it affected everyone.)
- **The logo (and the sidebar) went missing after a play-only account signed out and a full account signed in.** The play-only top bar borrows the logo, the name row and the menu from the sidebar, and on the way back it searched for them in the sidebar, where they no longer were, so the logo stayed behind. They are now remembered and put back exactly where they were. Found by following your exact steps (sign out of a play-only account, sign in as admin, no refresh).
- **Your edits to the built-in platforms are no longer undone.** Every start (and so every update) copied the built-in names, short names, families, colours and file types back over the platforms you had edited in Settings, so a short name like PSX or GENESIS went back to PS1 or GEN. A platform that already exists is now left exactly as you set it, and a built-in platform that is missing is still created. ScreenScraper / TheGamesDB ids that were never filled in are still filled from the built-in values; an id you set yourself is never replaced.
- **Play check: a game on its start-up test screen is no longer "blank".** Ghouls'n Ghosts (CPS1) starts with a self-test, grey text on a 98.6% black screen, which was judged "blank" and so never switched on. "Blank" now needs a screen that is black and almost nothing else (99.5% or more). A screen that is mostly black is also given up to 14 more seconds before it is judged, for games that take a while to start. New `--only TEXT` re-tests just the games whose title contains the text.
- **Play check `--cutoff` no longer gives up at the very start.** On a real MAME library it stopped after two games: 1971 and 1972 held one game each (Galaxy Game, Pong, which are not ordinary programs and fail on any core), and two failed years in a row ended the search. It now groups years with few games into steps of at least 8 games, ignores steps with too little evidence, only counts failures after a stretch that mostly ran, and prints a table of how many games ran in each step before suggesting a year.
- **The server stalled for over a minute when the DAT list loaded.** Counting which games matched each DAT file had no index and scanned the whole library for every entry (a test on a library the size of yours went from 46 seconds to 14 milliseconds). The server handles one request at a time, so the Sources page, folder browser and everything else waited behind it, which is why they sometimes failed or came back empty. An index fixes it (database version 18).
- **Adding a folder: the Browse panel is reliable.** It no longer appears open but empty when the page loads, shows "Reading the folder…" while the server answers (a busy NAS can take seconds), ignores an answer that arrives after you closed it or clicked again, and on a failure says what went wrong with a Try again button instead of staying blank.
- **The Sources list never goes blank:** while it loads it says so, and if the server is busy or the connection drops it shows "Could not load your folders" with a Try again button instead of an error you had to sign out to clear.
- **Welcome tour: no moving on while something is saving.** While a card is saving (a password change can take a few seconds), Back, Next and Skip are locked and a spinner shows, so a save is never left unconfirmed. The browser also keeps the new sign-in token after a password change.
- **Browser play can no longer be switched by members:** the per-game "Browser play on/off" control now needs an admin, in the app and on the server (it was open to any signed-in member).
- **A platform you add shows up in Sources straight away:** the platform picker on the Sources page was filled once, so a new platform only appeared after a page refresh. It now updates itself whenever the platform list changes and keeps the platform you had already chosen.
- **Wrong game's metadata on series titles:** on console platforms the first result from IGDB / TheGamesDB was taken, so "Destroy All Humans!" could be given "Destroy All Humans! 2"'s cover and description. A result whose title matches the one searched for now wins (roman numerals count as the same); only when nothing matches closely does it fall back to the first result.
- **"&amp;" and similar web-page codes no longer show up in titles.** Some provider text (for example IGDB's *Top Hunter - Roddy &amp; Cathy*) and some name lists (an FBNeo CSV had 159 such names) carried codes instead of characters. They are now turned back into normal characters when a match is saved and when a names CSV is read, and a one-time tidy-up on start-up fixes titles, developers, publishers, genres, descriptions and name-list entries that were already stored. A normal `&` and unknown codes are left exactly as they are.
- **Arcade matching picks the right game when a provider returns several with the same title.** The exact title wins over a longer one (*Sengoku* over *Sengoku Ace*); when several are equally exact, the one released in the year the names CSV gives wins (the 1994 *Bust-A-Move* for *Puzzle Bobble / Bust-A-Move*); roman numerals count as digits (*Crossed Swords 2* finds *Crossed Swords II*; *Mega Man X* is not *Mega Man 10*); and a game that exists but has no cover art is reported as no match instead of being swapped for a different game that has art. Neo Geo lookups also search Neo Geo CD.
- **Arcade matching copes with reordered and alternative names.** *2020 Super Baseball* now matches IGDB's *Super Baseball 2020* (the same words in another order are accepted; a longer, different title is still rejected), and for names like *Puzzle Bobble / Bust-A-Move* the part after the slash is searched too. Separately, *Refresh metadata* no longer reports another provider's "over quota" error when a provider that answered simply has no such game: you now get "no match", the true answer.
- **Neo Geo, CPS1/2/3, NAOMI and Atomiswave now look up covers like MAME does, and IGDB searches the right system.** Neo Geo was being searched on IGDB under the Game Boy Advance system, so its few matches were GBA games (*Double Dragon Advance*, *Dragon Ball Z: Buu's Fury*...). Neo Geo now searches Arcade, Neo Geo MVS and Neo Geo AES, and the other arcade platforms search Arcade. On all of these platforms the title must really match (no loose hits), IGDB is tried before TheGamesDB (whose monthly limit runs out on big sets, which made most lookups fail), and a lookup runs once the game has a trusted name, which the *Game names (CSV)* tool now provides for every arcade platform, not only MAME.
- **Settings: choosing a tab no longer loses your place.** (1) Opening a setting scrolled its title and description underneath the pinned header (most visibly in Platforms); panels now land clear of it. (2) With a controller or the keyboard, choosing a group or tab used to throw the focus to the cog icon because the tiles were rebuilt; the focus now stays on the tile you chose.
- **Duplicate finder is stricter, so it stops suggesting games that are not duplicates.** (1) On every arcade-romset platform (MAME, FinalBurn Neo, CPS1/2/3, Neo Geo, NAOMI, Atomiswave and a platform called Arcade) two zips group only when the MAME name list says one is a clone of the other. Two different zips that a metadata provider happened to give the same title (for example *Darkstalkers* and its sequel *Night Warriors*) are no longer paired. The Game names (CSV) tool now also saves the CSV's `clone_of` column, so clones group correctly on all of these platforms. (2) Disc-image games (PS2, Saturn and so on) with the same stored title but very different file sizes (one at least 1.6 times the other, over 50 MB) are still listed but carry a warning, *sizes differ a lot: probably not duplicates*.
- **Duplicate finder: copies no longer swap places when you lock or unlock one.** The locked or suggested copy used to jump to the first slot, so the padlock you had just clicked could end up on the other side. Copies now keep a fixed order (by file name); only the green outline and padlock change. The padlock tip is shorter so it no longer runs off the screen.
- **Duplicate finder no longer pairs the same arcade game across platforms.** An arcade game on FinalBurn Neo and the same game on MAME (for example `enduror.zip` in both) are different romsets for different emulators, not duplicates, so they are no longer grouped. Clones on the same platform still group under their parent.
- **Favourites are now truly per person.** One user starring a game used to star it for everyone, because the star was also written to a shared flag that the tiles read. Tiles, the Favourites filter, the home-page count and the detail window now read only your own favourites, and starring or un-starring changes only yours. (Stars set before this fix are still in each person's own list; the old shared flag is simply no longer read.)
- **Phone layout:** on small screens (phones, foldables like the Surface Duo) there was no way to open the menu. A top bar with a menu button now slides the sidebar in (it closes when you choose a page or platform, tap outside, or press Escape), and the game detail window fills the screen with larger touch-sized buttons.
- **Duplicate finder star can now be switched off on any copy**, including the suggested one: the star shows only your own choice (on = you pinned it, off = automatic), so clicking it toggles cleanly. The suggestion keeps its green outline.
- **Game detail window actions redesigned for touch:** Download, Play and Favourite stay as large buttons; everything else (Keep, collection, browser-play switch, hide, refresh, upload cover) is in a **More** menu with text labels and short explanations, and Delete stands apart. One row at any width, no hover needed (works on an iPad).
- **The Library keeps your place:** hiding a game, refreshing its metadata, favouriting it or changing it in the detail window no longer throws the grid back to the top. It reloads the tiles you had loaded and returns to the same scroll position. Changing a filter or pressing LIBRARY still starts from the top.
- **MAME: Fetch metadata after a CSV names import now works, and tries IGDB first.** Names applied from the Game names (CSV) tool are now recorded as trusted MAME names (previously title-based providers skipped MAME games unless a `-listxml` list was imported). For arcade romsets the order is ScreenScraper, then IGDB, then TheGamesDB, so an exhausted TheGamesDB quota no longer holds the lookup up.
- **Settings → Platforms:** the **Add platform** button stays in view under the pinned header while you scroll the list.
- **A newly picked cover shows straight away:** after choosing a match in *Identify this game*, the old cover could stay on screen (the browser kept its cached copy for a day). Cover links now change whenever the image does.
- **Disc and bracket tags are left out of metadata searches:** `[Disc 1]`, `(Disc 2 of 3)`, `- Disc 1`, `[CD2]` and stray `[!]`-style tags are removed before a provider is asked, so every disc of a game finds the same entry.
- **Fetch metadata with a platform selected only covers that platform** (the progress box names it). With no platform selected it runs over the whole library as before.
- **Sources on your own platforms now scan into them:** a folder added to a platform you created used to be scanned into "Other" (so the platform stayed empty and missing from the sidebar), and files with a custom extension were skipped. Existing ROMs filed under Other can be re-filed, or remove the source with its ROMs and add it again.
- **Add a folder no longer jumps** when you open the folder browser: the page keeps room for its scroll bar, and the Browse button keeps its label (it highlights while open and toggles the browser) instead of changing to "Hide browser".
- **Custom platforms now work everywhere:** adding a source (or uploading / re-filing a ROM) with a platform you created yourself was refused with "Platform is required". The check only knew the built-in list; it now accepts any platform in the library.
- **Duplicate finder no longer pairs different volumes, discs or numbered sequels.** Two games whose file names differ by a number (Volume 2 / Volume 3, Disc 1 / Disc 2, Part 1 / Part 2, Game 3 / Game 4) or a roman numeral (II / III) are kept apart even when a metadata provider gave them the same title. Regional and revision copies of the same volume are still found.
- **Removing a source did nothing:** the Remove popup's buttons never closed it or acted. It now shows its own buttons, and Cancel, Escape and clicking outside all close it.
- **Disable on a source** now works, and toggles back to Enable (it always sent "disable" before, so a disabled source could not be re-enabled from the button).
- A real cover no longer lets the initials placeholder show through it.
- The controller focus ring on the first row of the Library grid is no longer cut off at the top.
- The animated sign-in background now shows after signing out too, not only after a page refresh.
- The installer now prints the update command with its full path (`/usr/local/bin/game-sauce-update`), which `pct exec` needs.
- Refreshing the page now keeps you where you were: the same section, platform, search, filters, sort order and open Settings tile. (A fresh sign-in still starts on the Library home.)
- Signing out and back in now always lands on the Library, instead of the last view you had open (for example Settings).

## [0.1.0] - 2026-10-28 (first public release)

### Library and sources
- Scan folders **in place**: files are catalogued where they are and never moved, renamed or deleted.
- A platform is required for every source. Re-scans skip unchanged files, show a live
  **progress bar**, and clear a stale "missing" flag when a file is found again.
- One bad file no longer aborts a scan; failures are counted and reported with the first error.
- Add ROMs imports copies into `storage/`. Duplicate content is detected by SHA1.
- Library grid loads in pages as you scroll; **Select all** covers every ROM matching the filters.
- Collections: add and remove games, and a game can belong to several collections.

### Metadata
- Providers: ScreenScraper, TheGamesDB, IGDB, SteamGridDB (art fallback). Credentials are
  system-wide and admin-only. **Fetch metadata** now works through the whole library in one click.
- Manual match with a per-user default provider (star it in the dropdown).
- **MAME**: only `.zip` files are accepted. Import a MAME `-listxml` file under DAT files to turn
  short names (`sf2`) into real titles; title searches are strict so wrong covers are not applied.
- DAT verification (SHA1/CRC32 + size) with a have/want report. The "unverified" tile badge was removed.
- Admin tool to clear cover art for any platform.

### Play in the browser (EmulatorJS)
- Play button on tiles and in the detail panel for platforms that need no BIOS; fullscreen by default.
- **Per-user save states and in-game saves**, stored on the server, with a warning when a state was
  saved by a different EmulatorJS version.
- MAME is best effort: no Play button after 1990 by default (`GAMESAUCE_MAME_PLAY_MAX_YEAR`),
  and each game has its own on/off toggle.

### Accounts and admin
- Users with admin and member roles; sessions, audit log, in-app confirmation dialogs.
- Emulator guide with latest-release checks and an emulator vault.

### Interface
- Scales with screen size (fluid text size) from 1080p to 4K.
- Account bar under the logo with larger settings and sign-out buttons.
