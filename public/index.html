Add ROMs

How adding ROMs works here

Add ROMs copies the file into the library — it does not link or watch the original location. Pick files (or a folder of files) in the dropzone below; each file is hashed, deduplicated and stored under storage/roms/<platform>/<sha1>. Nothing is ever executed or auto-run. Want game-sauce to watch your existing folders without moving anything? Use Sources instead — those stay exactly where they are and only get re-scanned.

Database maintenance admin

ROMs can outlive their folder: removing a source with “keep ROMs”, or deleting a source whose ROMs were already imported, leaves orphaned rows with no valid source. They still appear in the library and in the platform list. Missing files (drive offline) are different — those still have a source and will re-appear on rescan.

Backups admin

A backup is one .tar.gz with a consistent copy of the database, the encryption key and every player's save states. Imported ROMs, covers and media are not included (your ROM folders are never touched). It contains password hashes and the key that protects your provider credentials, so store it as carefully as the server itself.

Restore from a backup

Upload a backup file to check what is inside it first. Nothing changes until you confirm. Before anything is replaced, a safety backup of the current data is saved in the folder above, and the data being replaced is kept (not deleted) so a restore can be undone. The server restarts and everyone signs in again afterwards.

DAT files (offline verification) admin

A No-Intro or Redump .dat lists every known-good dump with its size, CRC32, MD5 and SHA1. Importing one lets game-sauce verify each ROM locally — no API calls — and replace a guessed filename with the canonical title, region and revision.

Sources

Monitored folders, not copies

Sources are folders game-sauce watches in place. ROMs stay exactly where they are on your disks — the scan only records the path, size, date and hashes, then pulls metadata. Use this for your multi-drive collection. Use Add ROMs only when you want to import and store a copy inside game-sauce.

Emulators

How this works

One recommended emulator per popular platform, with links to the official site and download page — game-sauce never bundles binaries. The vault below holds your own emulator installers: upload one manually, or save the official GitHub release with one click and the server downloads it into storage/emulators for safekeeping. Latest-release checks hit the GitHub API live (10-minute cache); nightly-only projects report that instead of a version number.

Vault admin writes
